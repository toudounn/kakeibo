## 📝 家計簿アプリ開発メモ（Pages用まとめ）

### 🎯 開発の目的
- 家計簿アプリを作成し、支出を「登録・削除」できるようにする  
- 一覧表示で確認できるようにする  
- グラフで「月ごとの推移」「カテゴリ別」「支払方法別」を可視化する  

---

### ✅ 実装ステップ

1. **基本機能**
   - `FormDialog.tsx` で入力フォームを作成  
   - 登録ボタンで localStorage に保存  
   - 削除ボタンでデータを消去  

2. **一覧表示**
   - `AllTotal.tsx` でテーブル表示  
   - `App.tsx` で `items` を state 管理し、`FormDialog` → `AllTotal` に渡す  

3. **グラフ表示**
   - **棒グラフ**：月ごとの合計を比較  
   - **折れ線グラフ**：月ごとの推移を時系列で表示  
   - **円グラフ（カテゴリ別）**：食費・交通費などの割合を表示  
   - **円グラフ（支払方法別）**：現金・カード・電子マネーの割合を表示  

---

### ⚙️ 技術ポイント
- `react-chartjs-2` + `chart.js` を利用  
- `ChartJS.register(...)` は一度だけまとめて登録  
- グラフ再描画時のエラー回避 → `<Line key={labels.join(",")}>` のように `key` を付与  
- `responsive: true, maintainAspectRatio: false` を共通オプションに設定
